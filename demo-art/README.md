# Original demo artwork

These six geometric landscapes were written as SVG specifically for this
project's demonstration screenshots on 2026-11-02, with coding-assistant help.
They use only paths, circles and gradients; no downloaded photograph, website
wallpaper, font or third-party artwork was used as input.

Copyright 2026 lhfchym. Released under the MIT license in LICENSE.
`generate.py` regenerates the SVG sources. To render 1600×1000 PNG files, install
CairoSVG in a development environment and run:

    python generate.py --png-dir /path/to/demo-images

The generated filenames follow the application's local-gallery naming convention.
IDs demo01–demo06 are synthetic; they are not Wallhaven service IDs. Screenshots
must describe these as an offline local collection, not online search results.
